# Velora
Vite + React + GSAP (ScrollTrigger) + Lenis wig store with installation booking.
```
npm install
npm run dev
```
- Replace `public/hero.jpg` with your own photo (same filename, ~1920x1080).
- Product art is generated from `tone` colors in `src/api/client.js`; add real photos via the `image` field.
- Backend: set `VITE_USE_MOCK=false` and `VITE_API_URL` in `.env`. Endpoints are in `API.md`.
